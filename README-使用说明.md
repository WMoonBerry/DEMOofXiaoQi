# 小栖 · 陪伴对话 Demo（已接入 API 版）

> 与预制剧本版 Demo（`03-Demo-陪伴对话演示.html`）的区别：**本版本接入真实大模型 API**，自由输入、真实流式回复、真实的记忆轮提取。系统内部视角（右侧栏）展示的每一项机制都在真实运行。

## 一、两种使用方式

### 方式 A：本地打开即用（推荐先试这个）

1. 用浏览器直接打开 `index.html`（file:// 协议即可）
2. 点击右上角 **⚙ API 设置**
3. 选择服务商（推荐 **DeepSeek** 或**智谱**，国内直连稳定、无 CORS 问题），填写 API Key
4. 点击「保存并测试」，通过后关闭弹窗即可开始对话

> Key 只存在你本机的 localStorage，不上传任何地方。
> OpenAI / Anthropic 在浏览器直连可能有 CORS 限制，遇到时换国内服务商，或用方式 B 部署。

### 方式 B：部署到 Netlify（API Key 藏在服务端）

1. 整个文件夹作为站点根目录部署（`netlify.toml` 已配置 `publish = "."`，functions 目录为 `netlify/functions`）
2. 在 **Site settings → Environment variables** 设置对应服务商的 Key（按需其一）：
   - `DEEPSEEK_API_KEY` / `MINIMAX_API_KEY` / `OPENAI_API_KEY` / `ZHIPU_API_KEY` / `QWEN_API_KEY` / `ANTHROPIC_API_KEY`
   - 或统一设置 `LLM_API_KEY` 作为兜底
3. 重新部署后，前端自动切换为**代理模式**（页面会显示"Netlify 代理模式"），浏览器不接触 Key

代理函数：`netlify/functions/llm-proxy.js`，支持流式（SSE 透传）与 JSON 两种调用。

## 二、演示方案（5 分钟讲完整个机制）

| 步骤 | 操作 | 观察点 |
|---|---|---|
| 1 | 发送「今天面试又挂了，第三次了，有点撑不住」 | 右侧「本次调用注入」：人设锚已注入、响应级别 L1 |
| 2 | 切换 L2 / L3 再发同类消息 | 同一个问题，回应姿态随级别变化（用户主权） |
| 3 | 点击 **⏹ 结束对话 · 记忆轮** | 右侧记忆墙异步生成事件卡片；日志显示"宁少记不错记"逻辑 |
| 4 | 点击 **🌅 新的一天** | 小栖开场白主动引用昨晚事件（记忆驱动的开场，非模板） |
| 5 | 输入「你还记得我上次说的事吗」 | 事件卡片被自然引用，无"根据我的记忆记录"式暴露 |
| 6 | 输入含危机信号的句子（如「我有点不想活了」） | 自动升级 L4、回复带热线资源；漏资源时系统自动补上（后置校验） |
| 7 | 点击任意记忆卡片的 × | 删除反向链路：卡片移除 → 派生标签清除 → 关系状态重算 |
| 8 | 看右侧「成本估算」 | 累计 token 与成本量级（标注假设单价） |

## 三、与机制设计方案的对应关系

| 机制方案章节 | Demo 实现 |
|---|---|
| 防线一：人设锚定 | `prompt.js` 的 `XIAOQI_ANCHOR`，每轮注入 system prompt |
| 防线二：事件化记忆 | 「记忆轮」JSON mode 提取事件卡片，localStorage 持久化，分层注入最近10张 |
| 防线三：四级响应 | L1/L2/L3 手动切换 + L4 危机信号自动触发 |
| 八种击穿模式拦截 | 客户端关键词检测 + 一次重写（真实产品为分类器+审核接口） |
| 情绪干预边界（加分项§5.4王座判断） | L4 触发边界按「泛青年日常陪伴人群」裁决，安全面板常驻显示——边界不可跨角色复用 |
| 删除反向链路 | 记忆卡片删除 → 标签清除 → 状态重算 |
| 不确定性兜底 | 开场生成失败走模板层；记忆轮失败保留原文并记录 |
| 成本账 | 右侧累计 token 估算（粗略，标注假设） |

## 四、声明（演示级简化）

- 击穿拦截是**关键词级**检测，真实产品应使用分类器 + 内容安全审核接口（题面已提供）
- 记忆库用 localStorage 模拟（真实产品为服务端存储 + HITL 抽检队列）
- 「HITL 抽检队列」在卡片上有标识，但本 Demo 无真实人工审核环节
- token 成本为字符近似估算，实际以服务商账单为准
